# 🧊 냉장고 소분·재고 관리 (PWA)

소분 보관 + 소비기한 신호등 + 식단 추천 + 장보기를 한 번에 다루는 안드로이드용 설치형 웹앱입니다.
순수 HTML / CSS / Vanilla JS, 서버·DB 없이 휴대폰 안(localStorage)에 저장합니다.

## 파일 구조

```
fridge-pwa/
├── index.html            앱 뼈대 (상단바, 화면 영역, 하단 탭바 5개)
├── manifest.json         앱 이름·아이콘·전체화면 설정 → '홈 화면에 추가' 가능
├── sw.js                 Service Worker: 파일을 캐시해 오프라인에서도 실행
├── css/style.css         모바일 우선 디자인, 다크모드 자동 지원
├── js/recipes.js         한국 집밥·아기 반찬 레시피 50종 데이터
├── js/app.js             앱 로직 전체 (저장, 구역/칸, 소비기한, 일괄 입력, 추천, 장보기, 백업)
├── icons/                앱 아이콘 (192, 512, maskable 512, svg)
└── serve.ps1             (선택) 윈도우용 초간단 로컬 서버
```

## 주요 기능 위치

| 탭 | 기능 |
|---|---|
| 🧊 냉장고 | 임박 재료 TOP3, 구역 칩(냉장/냉동/실온/추가 구역), 칸별 아코디언(품목 수·임박 수), `-1팩` 원터치, 칸 추가/편집, 전체 임박순 보기 |
| ➕ 등록 | 자주 사는 재료 원터치 등록, 직접 입력(소비기한 자동 제안), 여러 줄 일괄 입력 |
| 🍳 뭐 먹지? | 보유·임박 재료 기준 레시피 매칭률 순 추천, 부족 재료 장보기 담기, 만개의레시피 조합 검색 |
| 🛒 장보기 | 체크리스트, 다 쓴 재료 제안, 입고(→등록 화면), 목록 공유 |
| ⚙️ 설정 | 구역 추가/이름/종류/순서/삭제, 칸 편집, 소비기한 기준표 수정, JSON 백업/복원, 앱 설치 |

품목을 누르면 수정 · 칸 이동(해동 시 소비기한 재계산) · 개봉 기록 · +1 · 장보기 · 삭제 메뉴가 열립니다.

### 일괄 입력 문법 (순서 자유)
```
삼겹살 120g 4팩 냉동 상칸
두부 1모 냉장 중칸
우유 900ml 1팩 문쪽 12/1      ← 날짜를 쓰면 그 날짜가 소비기한
애호박 1개 야채칸 D-3          ← D-3 또는 +3일 도 가능
```

## 로컬에서 테스트하기

Service Worker는 `file://`로 열면 동작하지 않아요. 간단한 로컬 서버로 열어 주세요. (localhost는 https가 아니어도 PWA 기능이 동작합니다.)

- **윈도우 (설치 필요 없음)**: 폴더에서 `powershell -ExecutionPolicy Bypass -File serve.ps1` → http://localhost:8080
- **Python이 있다면**: `python -m http.server 8080`
- **Node.js가 있다면**: `npx serve .`
- **VS Code**: 'Live Server' 확장 설치 → index.html 우클릭 → Open with Live Server

PC 크롬에서 F12 → 상단 📱(기기 툴바) 아이콘으로 휴대폰 화면 크기를 볼 수 있어요.
Application 탭 → Manifest / Service Workers에서 설치 가능 여부를 확인할 수 있습니다.

> ⚠️ 같은 와이파이에서 폰으로 `http://192.168.x.x:8080` 처럼 접속하면 화면은 보이지만, https가 아니라서 **설치·오프라인 기능은 동작하지 않아요.** 폰 설치는 아래 무료 배포를 이용하세요.

## 무료 배포 → 폰에 앱 설치

### 방법 A. Netlify Drop (제일 쉬움, 가입 1분)
1. https://app.netlify.com/drop 접속 (무료 가입/로그인)
2. 이 폴더 전체를 브라우저 창에 **끌어다 놓기**
3. `https://랜덤이름.netlify.app` 주소가 바로 생김 (사이트 설정에서 이름 변경 가능)
4. 수정 후 다시 올릴 때: 사이트 → Deploys → 폴더를 다시 끌어다 놓기

### 방법 B. GitHub Pages (오래 쓰기 좋음)
1. GitHub에서 새 저장소(Public) 생성 → `Add file → Upload files`로 폴더 안 파일 전부 업로드
2. 저장소 `Settings → Pages → Branch: main / (root)` 저장
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열림
   (경로가 모두 상대경로(`./`)라서 하위 주소에서도 그대로 동작해요)

### 방법 C. Cloudflare Pages
`Workers & Pages → Create → Pages → Upload assets`에서 폴더 업로드.

### 폰에 설치하기 (안드로이드 크롬)
1. 배포된 https 주소를 크롬으로 열기
2. 주소창 옆 **설치 아이콘** 또는 ⋮ 메뉴 → **앱 설치 / 홈 화면에 추가**
   (앱 안 ⚙️ 설정 → '홈 화면에 앱 설치' 버튼이 보이면 그걸 눌러도 돼요)
3. 홈 화면 아이콘으로 실행하면 주소창 없는 앱처럼 열리고, 한 번 연 뒤에는 비행기 모드에서도 동작합니다.

## 업데이트 · 데이터 주의사항

- 코드를 고쳐 다시 배포할 때는 `sw.js`의 `CACHE = 'fridge-pwa-v1'` 숫자를 올려 주세요. 새 버전은 **앱을 한 번 껐다 켠 뒤** 적용돼요.
- 데이터는 그 폰의 크롬(앱) 안에만 저장됩니다. 주소(도메인)가 바뀌면 데이터도 따로예요.
  기기 변경·주소 변경·크롬 데이터 삭제 전에는 **설정 → JSON 내보내기**로 백업하고, 새 곳에서 **가져오기** 하세요.
- 만개의레시피는 검색 주소만 새 창으로 여는 방식이라 크롤링·API 키가 필요 없습니다.
- 소비기한 기준은 일반적인 가정 보관 권장치예요. 제품 포장의 표시 기한을 우선해 주세요.
